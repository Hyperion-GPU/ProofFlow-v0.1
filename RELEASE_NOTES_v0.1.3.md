## ProofFlow v0.1.3 — Codex Workflow Demo

This release adds the 72-second ProofFlow showcase video for Codex-compatible AI coding agent workflows.

The demo shows the core audit loop:

1. Agent claim
2. Evidence graph
3. Policy gate
4. Undo metadata
5. Exportable Proof Packet
6. Final review by human maintainers

ProofFlow does not ban fast AI-assisted development. It makes it reviewable, traceable, reversible, and evidence-backed.
